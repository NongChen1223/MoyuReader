# 墨鱼阅读器（MoyuReader）功能需求说明

## 1. 文档定位

本文档记录 MoyuReader 当前已经实现的功能、页面职责、交互细节、平台差异和长期约定。
它不是宣传文案，也不是未来规划清单；后续 AI 或开发者接手时，应优先按本文档理解当前功能，不要凭印象重写交互。

当用户可感知的功能、入口、交互、视觉、平台支持或启动方式发生变化时，需要同步更新本文档。
如果只是内部重构、注释、测试或对用户无感的实现细节，可以不更新。

## 2. 产品定位

MoyuReader 是一个桌面端本地阅读器，重点服务本地小说阅读和摸鱼阅读场景。

当前技术栈：

- `React + TypeScript`：负责页面、路由、状态、样式和前端交互。
- `Electron`：负责桌面窗口、文件/目录选择器、主进程生命周期、IPC、macOS 原生老板模式浮窗。
- `Go`：负责小说解析、章节组织、全文搜索、配置读写和阅读进度持久化。

核心原则：

- 保留本地文件路径，不主动搬运或复制用户原始书籍文件。
- 阅读模式和老板模式共享同一本书的阅读进度。
- 普通阅读外观和老板模式外观分开记忆。
- 交互入口不要随意新增或移动；已有入口上完善功能优先。
- 视觉保持 Neubrutalism 风格，不退回通用玻璃拟态或无辨识度后台风。

## 3. 页面与路由

当前保留 3 个一级页面：

- `/home`：书架、目录和导入管理。
- `/reader`：普通阅读、章节目录、搜索、阅读外观、摸鱼模式入口。
- `/settings`：主题、阅读设置、存储路径、快捷键和设置内演示。

路由交互约定：

- 从顶层书架打开书籍，阅读页返回时回到 `/home`。
- 从目录内打开书籍，阅读页返回时回到对应目录。
- 从 Home 直接点击“老板模式”打开书籍，关闭老板模式后必须直接回 Home，不应短暂闪出普通阅读页。
- 从普通阅读页进入老板模式，关闭老板模式后应回到普通阅读页。

## 4. 书架页

### 4.1 展示与筛选

已实现能力：

- 支持 `grid` 和 `list` 两种视图。
- 支持按时间、大小、名称排序。
- 支持按书名或作者搜索。
- 顶层书架和目录内列表都使用同一套书架数据。
- 书架数据在前端本地持久化，重启后恢复。

交互细节：

- 搜索只影响当前展示结果，不应破坏原始书架数据。
- 当前目录内搜索只搜索目录内文件。
- 空状态文案需要区分顶层书架和目录内书架。

### 4.2 导入与目录

已实现能力：

- 支持导入本地文件。
- 支持创建自定义目录。
- 支持把已有单文件加入目录。
- 支持在目录内部继续导入新文件。
- 支持进入目录后返回顶层书架。

交互细节：

- 导入完成后只刷新书架或当前目录，不强制跳入阅读页。
- 目录内文件保留自己的阅读进度、最后阅读时间和顺序。
- 从目录内打开阅读页时，Reader 需要记住 `returnDirectoryId`，返回时回到原目录。
- 删除目录只删除书架记录和目录内记录，不删除本地原始文件。

### 4.3 书籍卡片

已实现能力：

- 单文件卡片支持普通阅读、老板模式阅读、重命名、删除。
- 目录卡片支持进入目录、快速阅读、导入到目录、重命名、删除。
- 支持多选删除。

交互细节：

- 多选模式下，点击卡片是切换选中，不是打开书籍。
- 多选删除范围只针对当前可见结果；搜索或目录切换后，不可见项不应继续保持选中。
- 删除确认要区分单书、目录和批量删除文案。
- 删除只移除应用内记录和阅读进度，不删除原始文件。
- 删除、重命名等按钮不得冒泡触发卡片打开。

### 4.4 重命名

已实现能力：

- 书籍和目录都支持项目内弹窗重命名。
- 重命名只影响书架显示名称，不修改原始文件名或文件夹名。

交互细节：

- 不使用浏览器 `prompt`。
- 重命名弹窗需要有明确说明：不会修改本地原始文件。

## 5. 普通阅读模式

### 5.1 打开与恢复

已实现能力：

- 从书架或目录打开书籍进入阅读页。
- 阅读页自动恢复上次章节和大致章内位置。
- 支持 TXT、EPUB、文本型 PDF 和 macOS 图片型 PDF 的正文展示。
- 支持较长章节的分块渲染，降低大文件滚动压力。

交互细节：

- 打开新书时不应残留上一本书内容。
- 重新打开同一本书时应尽量恢复到上次位置。
- 阅读进度保存以章节索引和总进度为基础，底部显示使用当前章节进度。

### 5.2 章节切换

已实现能力：

- 顶部工具栏支持上一章、下一章。
- 支持章节目录侧栏。
- 支持滚动到章节边界后自然衔接上一章或下一章。
- 支持底部当前章节进度条拖动定位。

交互细节：

- 点击目录章节必须跳到目标章节开头，正文滚动条同步置顶到目标章节开头。
- 点击上一章或下一章必须进入目标章节开头。
- 在第一章时，上一章按钮应禁用。
- 在最后一章时，下一章按钮应禁用。
- 章节边界滚轮切章必须有冷却，避免连续滚轮一次跨过多章。
- 自然滚动跨章后，顶部章节信息、目录高亮、底部章节进度必须同步。
- 从上一章边界切回时，应落到上一章末尾；从下一章边界切入时，应落到下一章开头。

### 5.3 章节目录

已实现能力：

- 阅读页支持打开章节目录。
- 当前章节有高亮。
- 点击章节跳转正文。

交互细节：

- 目录打开时应尽量定位到当前章节附近。
- 长章节标题不能撑破侧栏。
- 目录切章不能被滚动同步逻辑回弹到旧章节。

### 5.4 搜索

已实现能力：

- 支持当前小说全文搜索。
- 搜索结果展示关键字上下文。
- 点击搜索结果跳转并高亮命中内容。
- 支持 `Ctrl+F` 打开搜索。

交互细节：

- 搜索为空时不执行无意义搜索。
- 搜索跳转应定位到命中章节和对应内容附近。

### 5.5 阅读外观

已实现能力：

- 字体大小。
- 字体系列。
- 字重。
- 行高。
- 页面宽度百分比。
- 背景色。
- 文字颜色。

交互细节：

- 页面宽度使用百分比，不使用固定像素宽度。
- 普通阅读外观和设置页阅读外观使用同一套普通阅读设置。
- 普通阅读模式不包含透明度设置。
- 普通阅读模式的颜色选择器在关闭或失焦后再提交，避免拖动取色时高频重渲染大正文导致卡顿。
- 普通阅读外观不应污染老板模式外观；老板模式外观单独保存。

### 5.6 阅读页工具栏与窗口拖拽

已实现能力：

- 阅读页顶部工具栏提供返回、目录、章节信息、上一章、下一章、外观、搜索、摸鱼模式等入口。
- 普通阅读模式窗口顶部可拖动。

交互细节：

- 窗口拖拽区域不能覆盖按钮点击。
- 外观、目录、搜索面板应支持外部点击关闭。
- 从目录进入阅读页时，返回按钮文案和行为应回到目录；从顶层书架进入则回到书架。

## 6. 老板模式 / 摸鱼模式

### 6.1 模式类型

当前存在两套实现：

- macOS：优先使用 Electron 原生桌面浮窗老板模式。
- 非 macOS 或不支持原生浮窗时：退化为 WebView 内隐身摸鱼模式。

共同约定：

- 普通阅读和老板模式共享同一本书的阅读进度。
- 普通阅读模式读到某个位置，打开老板模式应尽量停在同一章节和相近位置。
- 老板模式读到新位置，退出后普通阅读或下次打开同一本书应尽量恢复到该位置。
- 进度允许因不同排版、窗口尺寸和字体差异存在小偏差，但不能跨很多章节。

### 6.2 macOS 原生老板浮窗

已实现能力：

- 独立透明浮窗展示正文。
- 主窗口进入老板模式时隐藏。
- 支持正文滚动和滚动条。
- 支持上一章、下一章。
- 支持章节目录。
- 支持关闭。
- 支持内容透明度。
- 支持本章进度拖动。
- 支持外观面板。
- 支持收纳伪装小狗桌宠。
- 支持窗口拖动和边缘/角落缩放。
- 支持窗口尺寸和位置记忆。

### 6.3 原生浮窗进入与关闭

交互细节：

- 从 Home 点击书籍老板模式入口时，直接打开老板浮窗，不应同时显示普通阅读页。
- 从 Home 进入老板模式后，点击关闭必须回到 Home；不能先闪出普通阅读页再回 Home。
- 从普通阅读页点击摸鱼模式进入老板模式后，点击关闭必须回到普通阅读页。
- 关闭前需要立即抓取当前浮窗阅读位置并持久化。
- 关闭后需要清理前端和主进程老板模式状态，避免关闭后自动重新弹出老板浮窗。

### 6.4 原生浮窗布局

已实现结构：

- 顶部控制栏：上一章、当前章节/目录、下一章、外观、挂件开关、关闭。
- 中间正文区：展示小说正文和图片。
- 底部控制栏：透明度、本章进度。

交互细节：

- 浮窗控件必须在同一个透明窗口内，不使用分离窗口。
- 鼠标进入顶部或底部区域时，顶部/底部控制栏渐显。
- 鼠标移动到正文中间区域时，顶部/底部控制栏渐隐，只保留正文阅读内容。
- 控制栏应贴合窗口边框，按钮是内嵌分段按钮，不是悬浮胶囊按钮。
- 顶部按钮按阅读导航和窗口操作分组，高度、边框、间距和对齐必须统一。
- 第一章时上一章禁用，最后一章时下一章禁用。
- 目录、外观等弹层打开时，控制栏应保持可见，不被自动隐藏。

### 6.5 原生浮窗正文滚动与切章

已实现能力：

- 浮窗正文支持鼠标滚轮。
- 正文滚动会回传当前章节和章内进度。
- 支持本章进度滑杆拖动定位。
- 支持滚动到章节边界后切换上一章或下一章。

交互细节：

- 浮窗内滚轮事件优先由浮窗消费，不穿透到底层应用。
- 目录弹层和外观弹层内滚轮只滚动弹层自身，不滚动正文。
- 点击上一章、下一章或目录切章时，正文必须定位到目标章节开头，本章进度重置到 0%。
- 老板模式读取和写入章节进度统一使用章节高度百分比，尽量和普通阅读模式对齐。
- 刚滚动完马上关闭时，需要立即同步当前浮窗位置，不能保存上一帧位置。

### 6.6 原生浮窗目录

已实现能力：

- 点击当前章节按钮打开章节目录。
- 目录弹层展示章节列表。
- 当前章节高亮。
- 点击章节切换。

交互细节：

- 目录弹层可以不透明，以保证可读性。
- 目录外点击收起。
- 每次打开目录应滚动到当前章节附近。
- 目录项之间要有明确间距，hover 和 active 不能粘连。
- hover 和 active 使用项目风格的描边、偏移阴影和主题强调色。

### 6.7 原生浮窗外观

已实现能力：

- 字号。
- 字重。
- 行高。
- 文字颜色。
- 跟随应用主题。

交互细节：

- 老板模式外观独立于普通阅读外观持久化。
- 老板模式外观跨书籍继承同一套配置，不按单本书保存。
- 老板模式颜色选择器使用原生颜色选择器。
- 打开颜色选择器时，浮窗会临时取消 always-on-top，避免系统颜色面板被浮窗遮挡；关闭或失焦后恢复置顶。
- 外观面板内容超过窗口高度时，面板自身可滚动，不应被底部栏遮挡。

### 6.8 原生浮窗透明度

已实现能力：

- 老板模式支持内容透明度滑杆。
- 透明度影响正文文字和图片。
- 透明度跨书籍记忆。

交互细节：

- 透明度只属于老板模式，不属于普通阅读模式。
- 拖动透明度时，不应被主窗口或后端旧状态反复拉回。
- 透明度调整应即时作用到浮窗内容。

### 6.9 原生浮窗拖动与缩放

已实现能力：

- 浮窗展开状态下支持拖动。
- 浮窗展开状态下支持边缘和角落缩放。
- 用户最后调整的展开窗口尺寸和位置会被记忆。

交互细节：

- 正文非滚动条区域可左键拖动窗口。
- 顶部/底部控制栏空白区域可拖动窗口。
- 按钮、输入框、滑杆、目录弹层、外观弹层、正文滚动条、窗口缩放边缘不能被拖动逻辑抢占。
- 鼠标贴近窗口边缘时应出现对应 resize 鼠标样式。
- 拖动或缩放后保存展开窗口 bounds。
- 不同书籍打开老板模式时，应复用最后一次保存的展开窗口尺寸和位置。

### 6.10 收纳伪装小狗

已实现能力：

- 老板浮窗支持“挂件开 / 挂件关”。
- 开启后，浮窗可收纳为小型像素风小狗桌宠。
- 小狗窗口尺寸小于普通浮窗。
- 小狗支持拖动。
- 单击小狗恢复老板浮窗。

交互细节：

- 点击“挂件开”后，需要立即收纳成小狗，让用户感知开关生效。
- 挂件开启时，鼠标移出展开浮窗后应自动收纳成小狗。
- 小狗应出现在原展开窗口中心点。
- 从小狗恢复窗口时，展开窗口也应以小狗中心点为中心恢复。
- 小狗恢复后要有短暂冷却，避免窗口尺寸变化触发 `mouseleave` 后又立刻收回。
- 拖动小狗后不能误触单击恢复。
- 小狗图标使用项目风格的像素小狗，不使用大卡片式挂件。

### 6.11 WebView 隐身摸鱼模式

已实现能力：

- 在非 macOS 原生浮窗场景下，使用阅读页内隐身模式。
- 支持 basic / full 隐身级别。
- 支持唤出延迟和隐藏延迟。
- 支持透明度。
- 支持右键打开老板模式面板。
- 支持收纳伪装演示式挂件。

交互细节：

- 鼠标移出阅读框后可收纳，双击挂件恢复。
- 挂件位置可拖动并保存。
- 右键面板支持模式、透明度、唤出延迟、隐藏延迟、收纳伪装、常显和退出。
- WebView 隐身模式仍使用普通阅读页 DOM，不是独立 Electron 浮窗。

## 7. 文件格式

### 7.1 TXT

已实现能力：

- 支持读取本地 TXT。
- 支持常见章节标题识别。
- 支持章节阅读、搜索、进度保存。

章节识别覆盖常见模式：

- `第 X 章`
- `Chapter 1`
- 数字编号
- 方括号标题

### 7.2 EPUB

已实现能力：

- 支持 metadata 标题和作者。
- 支持封面解析。
- 支持 spine 顺序章节。
- 支持基础 HTML 正文。
- 支持正文图片转换为可显示 data URL。
- 支持章节阅读、搜索、进度保存。

交互细节：

- EPUB 图片必须限制在正文版心内。
- EPUB 正文结构应尽量保留段落、标题、列表、引用和图片。
- 摸鱼浮窗中 EPUB 图片同样应受正文区域约束，并跟随透明度。

### 7.3 PDF

已实现能力：

- 支持可提取文本的文本型 PDF。
- 支持读取 PDF metadata 中的标题和作者。
- macOS 支持无可读文本 PDF 的按页图片渲染，用于扫描版 PDF 或漫画 PDF。

交互细节：

- 文本型 PDF 提取正文后沿用章节识别。
- macOS 图片型 PDF 按页渲染为图片章节。
- PDF 图片页必须限制在阅读正文区域内。

## 8. 设置页

### 8.1 主题设置

已实现能力：

- 白天模式。
- 夜间模式。
- 护眼模式。

交互细节：

- 主题需要影响 Home、Reader、Settings 和 macOS 原生老板浮窗。
- 老板模式浮窗的按钮、弹层、滑杆和文字颜色都要跟随主题变量。

### 8.2 阅读设置

已实现能力：

- 字体大小。
- 字体系列。
- 字重。
- 行高。
- 页面宽度。
- 背景色。
- 文字颜色。
- 老板模式透明度。
- 隐身级别。
- 唤出延迟。
- 隐藏延迟。
- 收纳伪装预览。

交互细节：

- 设置页颜色选择器可即时提交，因为没有大正文重渲染压力。
- 设置页阅读外观影响普通阅读模式。
- 老板模式专用外观在老板浮窗内调整，不与普通阅读设置混用。

### 8.3 存储管理

已实现能力：

- 展示真实本机数据目录。
- 支持通过系统目录选择器修改数据目录。
- 修改后写入 Go 配置。

交互细节：

- 文案必须说明原始书籍文件仍保留在本地原路径。
- 阅读进度存储在当前数据目录下。

### 8.4 快捷键

已实现能力：

- 支持录制式快捷键设置。
- 支持快捷键冲突校验。
- 支持恢复默认快捷键。

当前默认快捷键：

- `Ctrl+Shift+H`：老板键 / 摸鱼模式切换。
- `Escape`：快速隐藏。
- `Ctrl+F`：搜索。
- `ArrowLeft`：上一章。
- `ArrowRight`：下一章。
- `Ctrl+H`：返回书架。

### 8.5 阅读统计

当前设置页存在阅读统计 UI 区域，但真实统计数据尚未接入。
文案和后续实现不能把它当作真实统计功能使用。

## 9. 数据持久化

### 9.1 前端本地状态

已实现持久化：

- 主题：`themeStore`。
- 普通阅读设置：`settingsStore`。
- 老板模式透明度、外观、收纳伪装和快捷键：`settingsStore`。
- 书架、目录、目录内文件、阅读入口来源：`libraryStore`。

### 9.2 Go 后端状态

已实现持久化：

- 配置文件：`config/config.{env}.json`。
- 阅读进度：当前 `DataDir/progress.json`。

原则：

- 不主动移动用户原始书籍文件。
- 以“文件路径 + 阅读状态”的方式管理本地阅读。
- 用户修改数据目录后，配置和进度路径应跟随变化。

## 10. 视觉风格

当前视觉方向：

- Neubrutalism。
- 硬描边。
- 粗边框。
- 偏移阴影。
- 低模糊。
- 低光污染。
- 强结构。

控件规则：

- 按钮、弹层、滑杆、输入框保持项目内统一风格。
- 阅读页优先纯文字按钮，减少图标噪音。
- Home、Reader、Settings 和老板浮窗都要保持同一视觉语言。
- 不回退到紫色泛光、玻璃拟态或通用后台 UI。

主题规则：

- `light`：亮底、偏蓝主色、信息清晰。
- `dark`：夜间深色主题，避免刺眼高亮。
- `sepia`：护眼暖色阅读场景。

## 11. 平台差异

### 11.1 macOS

已实现：

- Electron 原生老板浮窗。
- 图片型 PDF 按页渲染。
- 系统文件和目录选择器。

注意：

- 原生老板浮窗是 macOS 重点体验。
- 浮窗颜色选择器打开时需要临时取消 always-on-top，避免遮挡系统颜色面板。

### 11.2 非 macOS

已实现：

- 普通阅读。
- WebView 内隐身摸鱼模式。
- 文本型 PDF 阅读。

注意：

- 不使用 macOS 原生老板浮窗。
- 图片型 PDF 按页渲染不作为非 macOS 已实现能力记录。

## 12. 开发入口

当前开发入口：

- 根目录运行 `pnpm dev`。
- 前端单独运行可用 `pnpm --dir frontend dev`。
- 前端构建验证使用 `pnpm --dir frontend build`。
- Go 后端变更后验证使用 `go test ./...`。

当前根目录 `pnpm dev` 会同时启动 Vite、Electron 和 Go 服务。

- 页面入口变化。
