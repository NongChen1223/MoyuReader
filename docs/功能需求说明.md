# 墨鱼阅读器（MoyuReader）功能需求说明

## 1. 文档定位

本文档记录 MoyuReader 当前已经实现的功能、页面职责、交互细节、平台差异和长期约定。
它不是宣传文案，也不是未来规划清单；后续 AI 或开发者接手时，应优先按本文档理解当前功能，不要凭印象重写交互。

当用户可感知的功能、入口、交互、视觉、平台支持或启动方式发生变化时，需要同步更新本文档。
如果只是内部重构、注释、测试或对用户无感的实现细节，可以不更新。

## 2. 产品定位

MoyuReader 是一个桌面端本地阅读器，重点服务本地小说阅读和摸鱼阅读场景。

当前技术栈：

- `React + TypeScript`：负责页面、路由、状态、样式和前端交互。
- `Electron`：负责桌面窗口、文件/目录选择器、主进程生命周期、IPC、macOS 原生老板模式浮窗。
- `Go`：负责小说解析、章节组织、全文搜索、配置读写和阅读进度持久化。

核心原则：

- 保留本地文件路径，不主动搬运或复制用户原始书籍文件。
- 阅读模式和老板模式共享同一本书的阅读进度。
- 普通阅读外观和老板模式外观分开记忆。
- 交互入口不要随意新增或移动；已有入口上完善功能优先。
- 视觉保持 Neubrutalism 风格，不退回通用玻璃拟态或无辨识度后台风。

## 3. 页面与路由

当前保留 3 个一级页面：

- `/home`：书架、目录和导入管理。
- `/reader`：普通阅读、章节目录、搜索、阅读外观、摸鱼模式入口。
- `/settings`：主题、阅读设置、挂件设置、快捷键和设置内演示。

路由交互约定：

- 从顶层书架打开书籍，阅读页返回时回到 `/home`。
- 从目录内打开书籍，阅读页返回时回到对应目录。
- 从 Home 直接点击“老板模式”打开书籍，关闭老板模式后必须直接回 Home，不应短暂闪出普通阅读页。
- 从普通阅读页进入老板模式，关闭老板模式后应回到普通阅读页。

## 4. 书架页

### 4.1 展示与筛选

已实现能力：

- 支持 `grid` 和 `list` 两种视图。
- 支持按时间、大小、名称排序。
- 支持按书名或作者搜索。
- 顶层书架和目录内列表都使用同一套书架数据。
- 书架数据在前端本地持久化，重启后恢复。

交互细节：

- 搜索只影响当前展示结果，不应破坏原始书架数据。
- 当前目录内搜索只搜索目录内文件。
- 空状态文案需要区分顶层书架和目录内书架。

### 4.2 导入与目录

已实现能力：

- 支持导入本地文件。
- 支持创建自定义目录。
- 支持把已有单文件加入目录。
- 支持在目录内部继续导入新文件。
- 支持进入目录后返回顶层书架。

交互细节：

- 导入完成后只刷新书架或当前目录，不强制跳入阅读页。
- 目录内文件保留自己的阅读进度、最后阅读时间和顺序。
- 从目录内打开阅读页时，Reader 需要记住 `returnDirectoryId`，返回时回到原目录。
- 删除目录只删除书架记录和目录内记录，不删除本地原始文件。

### 4.3 书籍卡片

已实现能力：

- 单文件卡片支持普通阅读、老板模式阅读、打开所在目录、重命名、删除。
- 目录卡片支持进入目录、快速阅读、导入到目录、重命名、删除。
- 支持多选删除。
- 单文件卡片展示文件格式和内容类型，例如小说、漫画、文档。

交互细节：

- 多选模式下，点击卡片是切换选中，不是打开书籍。
- 多选删除范围只针对当前可见结果；搜索或目录切换后，不可见项不应继续保持选中。
- 删除确认要区分单书、目录和批量删除文案。
- 删除只移除应用内记录和阅读进度，不删除原始文件。
- 删除、重命名等按钮不得冒泡触发卡片打开。
- “打开所在目录”调用系统文件管理器定位原始书籍文件；macOS 表现为 Finder，Windows 表现为资源管理器。

### 4.4 重命名

已实现能力：

- 书籍和目录都支持项目内弹窗重命名。
- 重命名只影响书架显示名称，不修改原始文件名或文件夹名。
- 单本书籍编辑弹窗支持手动修改内容类型：自动、小说、漫画、文档。

交互细节：

- 不使用浏览器 `prompt`。
- 重命名弹窗需要有明确说明：不会修改本地原始文件。
- 内容类型用于后续决定默认阅读/翻页模式；自动识别只是建议，用户手动修改后应持久化。

## 5. 普通阅读模式

### 5.1 打开与恢复

已实现能力：

- 从书架或目录打开书籍进入阅读页。
- 阅读页自动恢复上次章节和大致章内位置。
- 支持 TXT、EPUB、文本型 PDF 和 macOS 图片型 PDF 的正文展示。
- 支持较长章节的分块渲染，降低大文件滚动压力。

交互细节：

- 打开新书时不应残留上一本书内容。
- 重新打开同一本书时应尽量恢复到上次位置。
- 阅读进度保存以章节索引和总进度为基础，底部显示使用当前章节进度。

### 5.2 章节切换

已实现能力：

- 顶部工具栏支持上一章、下一章。
- 支持章节目录侧栏。
- 支持滚动到章节边界后自然衔接上一章或下一章。
- 支持底部当前章节进度条拖动定位。

交互细节：

- 点击目录章节必须跳到目标章节开头，正文滚动条同步置顶到目标章节开头。
- 点击上一章或下一章必须进入目标章节开头。
- 在第一章时，上一章按钮应禁用。
- 在最后一章时，下一章按钮应禁用。
- 章节边界滚轮切章必须有冷却，避免连续滚轮一次跨过多章。
- 自然滚动跨章后，顶部章节信息、目录高亮、底部章节进度必须同步。
- 从上一章边界切回时，应落到上一章末尾；从下一章边界切入时，应落到下一章开头。

### 5.3 章节目录

已实现能力：

- 阅读页支持打开章节目录。
- 当前章节有高亮。
- 点击章节跳转正文。

交互细节：

- 目录打开时应尽量定位到当前章节附近。
- 长章节标题不能撑破侧栏。
- 目录切章不能被滚动同步逻辑回弹到旧章节。

### 5.4 搜索

已实现能力：

- 支持当前小说全文搜索。
- 搜索结果展示关键字上下文。
- 点击搜索结果跳转并高亮命中内容。
- 支持 `Ctrl+F` 打开搜索。

交互细节：

- 搜索为空时不执行无意义搜索。
- 搜索跳转应定位到命中章节和对应内容附近。

### 5.5 阅读外观

已实现能力：

- 字体大小。
- 字体系列。
- 字重。
- 行高。
- 页面宽度百分比。
- 背景色。
- 文字颜色。

交互细节：

- 页面宽度使用百分比，不使用固定像素宽度。
- 普通阅读外观和设置页阅读外观使用同一套普通阅读设置。
- 普通阅读模式不包含透明度设置。
- 普通阅读模式的颜色选择器在关闭或失焦后再提交，避免拖动取色时高频重渲染大正文导致卡顿。
- 普通阅读外观不应污染老板模式外观；老板模式外观单独保存。

### 5.6 阅读页工具栏与窗口拖拽

已实现能力：

- 阅读页顶部工具栏提供返回、目录、章节信息、上一章、下一章、外观、搜索、摸鱼模式等入口。
- 普通阅读模式窗口顶部可拖动。

交互细节：

- 窗口拖拽区域不能覆盖按钮点击。
- 外观、目录、搜索面板应支持外部点击关闭。
- 从目录进入阅读页时，返回按钮文案和行为应回到目录；从顶层书架进入则回到书架。

## 6. 老板模式 / 摸鱼模式

### 6.1 模式类型

当前存在两套实现：

- macOS：优先使用 Electron 原生桌面浮窗老板模式。
- 非 macOS 或不支持原生浮窗时：退化为 WebView 内隐身摸鱼模式。

共同约定：

- 普通阅读和老板模式共享同一本书的阅读进度。
- 普通阅读模式读到某个位置，打开老板模式应尽量停在同一章节和相近位置。
- 老板模式读到新位置，退出后普通阅读或下次打开同一本书应尽量恢复到该位置。
- 进度允许因不同排版、窗口尺寸和字体差异存在小偏差，但不能跨很多章节。

### 6.2 macOS 原生老板浮窗

已实现能力：

- 独立透明浮窗展示正文。
- 主窗口进入老板模式时隐藏。
- 支持正文滚动和滚动条。
- 支持上一章、下一章。
- 支持章节目录。
- 支持关闭。
- 支持内容透明度。
- 支持本章进度拖动。
- 支持外观面板。
  - 支持收纳伪装小狗桌宠。
- 支持窗口拖动和边缘/角落缩放。
- 支持窗口尺寸和位置记忆。

### 6.3 原生浮窗进入与关闭

交互细节：

- 从 Home 点击书籍老板模式入口时，直接打开老板浮窗，不应同时显示普通阅读页。
- 从 Home 进入老板模式后，点击关闭必须回到 Home；不能先闪出普通阅读页再回 Home。
- 从普通阅读页点击摸鱼模式进入老板模式后，点击关闭必须回到普通阅读页。
- 关闭前需要立即抓取当前浮窗阅读位置并持久化。
- 关闭后需要清理前端和主进程老板模式状态，避免关闭后自动重新弹出老板浮窗。

### 6.4 原生浮窗布局

已实现结构：

- 顶部控制栏：上一章、当前章节/目录、下一章、外观、挂件开关、关闭。
- 中间正文区：展示小说正文和图片。
- 底部控制栏：透明度、本章进度。

交互细节：

- 浮窗控件必须在同一个透明窗口内，不使用分离窗口。
- 鼠标进入顶部或底部区域时，顶部/底部控制栏渐显。
- 鼠标移动到正文中间区域时，顶部/底部控制栏渐隐，只保留正文阅读内容。
- 控制栏应贴合窗口边框，按钮是内嵌分段按钮，不是悬浮胶囊按钮。
- 顶部按钮按阅读导航和窗口操作分组，高度、边框、间距和对齐必须统一。
- 第一章时上一章禁用，最后一章时下一章禁用。
- 目录、外观等弹层打开时，控制栏应保持可见，不被自动隐藏。

### 6.5 原生浮窗正文滚动与切章

已实现能力：

- 浮窗正文支持鼠标滚轮。
- 正文滚动会回传当前章节和章内进度。
- 支持本章进度滑杆拖动定位。
- 支持滚动到章节边界后切换上一章或下一章。

交互细节：

- 浮窗内滚轮事件优先由浮窗消费，不穿透到底层应用。
- 目录弹层和外观弹层内滚轮只滚动弹层自身，不滚动正文。
- 点击上一章、下一章或目录切章时，正文必须定位到目标章节开头，本章进度重置到 0%。
- 老板模式读取和写入章节进度统一使用章节高度百分比，尽量和普通阅读模式对齐。
- 刚滚动完马上关闭时，需要立即同步当前浮窗位置，不能保存上一帧位置。

### 6.6 原生浮窗目录

已实现能力：

- 点击当前章节按钮打开章节目录。
- 目录弹层展示章节列表。
- 当前章节高亮。
- 点击章节切换。

交互细节：

- 目录弹层可以不透明，以保证可读性。
- 目录外点击收起。
- 每次打开目录应滚动到当前章节附近。
- 目录项之间要有明确间距，hover 和 active 不能粘连。
- hover 和 active 使用项目风格的描边、偏移阴影和主题强调色。

### 6.7 原生浮窗外观

已实现能力：

- 字号。
- 字重。
- 行高。
- 文字颜色。
- 跟随应用主题。

交互细节：

- 老板模式外观独立于普通阅读外观持久化。
- 老板模式外观跨书籍继承同一套配置，不按单本书保存。
- 老板模式颜色选择器使用原生颜色选择器。
- 打开颜色选择器时，浮窗会临时取消 always-on-top，避免系统颜色面板被浮窗遮挡；关闭或失焦后恢复置顶。
- 外观面板内容超过窗口高度时，面板自身可滚动，不应被底部栏遮挡。

### 6.8 原生浮窗透明度

已实现能力：

- 老板模式支持内容透明度滑杆。
- 透明度影响正文文字和图片。
- 透明度跨书籍记忆。

交互细节：

- 透明度只属于老板模式，不属于普通阅读模式。
- 拖动透明度时，不应被主窗口或后端旧状态反复拉回。
- 透明度调整应即时作用到浮窗内容。

### 6.9 原生浮窗拖动与缩放

已实现能力：

- 浮窗展开状态下支持拖动。
- 浮窗展开状态下支持边缘和角落缩放。
- 用户最后调整的展开窗口尺寸和位置会被记忆。

交互细节：

- 正文非滚动条区域可左键拖动窗口。
- 顶部/底部控制栏空白区域可拖动窗口。
- 按钮、输入框、滑杆、目录弹层、外观弹层、正文滚动条、窗口缩放边缘不能被拖动逻辑抢占。
- 鼠标贴近窗口边缘时应出现对应 resize 鼠标样式。
- 拖动或缩放后保存展开窗口 bounds。
- 不同书籍打开老板模式时，应复用最后一次保存的展开窗口尺寸和位置。

### 6.10 收纳伪装小狗

已实现能力：

- 老板浮窗支持“挂件开 / 挂件关”。
- 开启后，浮窗可收纳为小型像素风桌宠。
- 桌宠形象支持狗和猫。
- 小狗窗口尺寸小于普通浮窗。
- 小狗支持拖动。
- 桌宠恢复老板浮窗的触发方式由挂件设置决定。

交互细节：

- 点击“挂件开”后，需要立即收纳成小狗，让用户感知开关生效。
- 挂件开启时，鼠标移出展开浮窗后应自动收纳成小狗。
- 桌宠应出现在原展开窗口中心点。
- 从桌宠恢复窗口时，展开窗口也应以桌宠中心点为中心恢复。
- 桌宠恢复后要有短暂冷却，避免窗口尺寸变化触发 `mouseleave` 后又立刻收回。
- 拖动桌宠后不能误触恢复。
- 桌宠图标使用项目风格的像素宠物，不使用大卡片式挂件。
- 原生浮窗挂件读取设置页选择的宠物形象。
- 原生浮窗挂件读取设置页选择的恢复触发方式：单击、双击、鼠标移入、老板键。
- 开启“允许桌宠自己游荡”后，挂件优先播放走路游荡动画；真实桌面自动移动逻辑仍为待规划。

### 6.11 WebView 隐身摸鱼模式

已实现能力：

- 在非 macOS 原生浮窗场景下，使用阅读页内隐身模式。
- 支持 basic / full 隐身级别。
- 支持唤出延迟和隐藏延迟。
- 支持透明度。
- 支持右键打开老板模式面板。
- 支持收纳伪装挂件。

交互细节：

- 鼠标移出阅读框后可收纳，恢复方式由挂件设置决定。
- 挂件位置可拖动并保存。
- 挂件读取设置页选择的狗/猫形象、游荡开关和恢复触发方式。
- 右键面板支持模式、透明度、唤出延迟、隐藏延迟、收纳伪装、常显和退出。
- WebView 隐身模式仍使用普通阅读页 DOM，不是独立 Electron 浮窗。

## 7. 文件格式

### 7.1 TXT

已实现能力：

- 支持读取本地 TXT。
- 支持常见章节标题识别。
- 支持章节阅读、搜索、进度保存。

章节识别覆盖常见模式：

- `第 X 章`
- `Chapter 1`
- 数字编号
- 方括号标题

### 7.2 EPUB

已实现能力：

- 支持 metadata 标题和作者。
- 支持封面解析。
- 支持 spine 顺序章节。
- 支持基础 HTML 正文。
- 支持正文图片转换为可显示 data URL。
- 支持章节阅读、搜索、进度保存。

交互细节：

- EPUB 图片必须限制在正文版心内。
- EPUB 正文结构应尽量保留段落、标题、列表、引用和图片。
- 摸鱼浮窗中 EPUB 图片同样应受正文区域约束，并跟随透明度。

### 7.3 PDF

已实现能力：

- 支持可提取文本的文本型 PDF。
- 支持读取 PDF metadata 中的标题和作者。
- macOS 支持无可读文本 PDF 的按页图片渲染，用于扫描版 PDF 或漫画 PDF。

交互细节：

- 文本型 PDF 提取正文后沿用章节识别。
- macOS 图片型 PDF 按页渲染为图片章节。
- PDF 图片页必须限制在阅读正文区域内。

### 7.4 内容类型识别

已实现能力：

- 书籍记录包含内容类型字段：自动、小说、漫画、文档。
- 导入或打开书籍时会进行基础自动识别。
- TXT 默认识别为小说。
- EPUB 根据图片数量和文本量粗略识别小说或漫画。
- PDF 根据可提取文本量和图片页特征粗略识别文档或漫画。
- 用户可在书籍编辑弹窗中手动修改内容类型，手动修改优先于自动识别。

交互细节：

- 自动识别不能作为绝对结论，只作为默认建议。
- 内容类型识别错了必须允许用户纠正。
- 内容类型后续用于决定默认翻页/阅读模式，例如小说分页、漫画连续长图或 PDF 单页适高。

## 8. 设置页

### 8.1 主题设置

已实现能力：

- 白天模式。
- 夜间模式。
- 护眼模式。

交互细节：

- 主题需要影响 Home、Reader、Settings 和 macOS 原生老板浮窗。
- 老板模式浮窗的按钮、弹层、滑杆和文字颜色都要跟随主题变量。

### 8.2 阅读设置

已实现能力：

- 字体大小。
- 字体系列。
- 字重。
- 行高。
- 页面宽度。
- 背景色。
- 文字颜色。
- 阅读方式选项。
- 老板模式透明度。
- 隐身级别。
- 唤出延迟。
- 隐藏延迟。

交互细节：

- 设置页颜色选择器可即时提交，因为没有大正文重渲染压力。
- 设置页阅读外观影响普通阅读模式。
- 阅读方式不属于外观设置，普通阅读页需要使用独立“阅读方式”按钮打开选择面板，设置页也需要单独展示“阅读方式”区域。
- 翻页模式文案必须面向普通用户，避免只显示“连续滚动、分页”等专业名词；例如 PDF 漫画想一直看时，用户应能直接选择“漫画连续看（不用翻页）”或“PDF 连续看”。
- “漫画连续看（不用翻页）”和“PDF 连续看”会扩大后续章节/页面预加载窗口，适合 PDF 漫画、图片型漫画等一页一章的内容，避免每页都必须触底后才等待下一页加载。
- “一直往下看（小说/文档）”会比普通章节阅读预加载更多后续章节，减少长文档连续阅读时的断点感。
- “按章节阅读（适合小说）”保持轻量章节窗口，适合普通小说阅读和低内存场景。
- 进度条语义需要跟随阅读方式切换：“按章节阅读”和“自动向下滚”显示并拖动当前章节进度；连续阅读、漫画、PDF、分页类模式显示并拖动整本进度。
- 切换阅读方式或拖动进度条后，Reader 必须按当前阅读方式重新维护章节/页面加载窗口，不能退回只显示单页/单章。
- 摸鱼模式需要沿用普通阅读模式的阅读方式和进度条语义；原生老板浮窗预加载也需要尊重当前阅读方式。
- 老板模式专用外观在老板浮窗内调整，不与普通阅读设置混用。

### 8.3 挂件设置

已实现能力：

- 独立于阅读设置的“挂件设置”栏。
- 支持选择桌宠形象：狗、猫。
- 支持设置是否允许桌宠自己游荡。
- 支持设置挂件恢复方式：单击、双击、鼠标移入、按老板键。
- 支持收纳伪装预览。
- 预览展示当前宠物的走路、特殊待机、张嘴吃文件和疑问反馈动作。
- WebView 挂件支持在当前窗口可视范围内自动游荡。
- WebView 挂件支持拖拽文件悬浮和投喂反馈。
- 支持文件格式初步判断：`txt`、`epub`、`pdf` 视为可吃；其他格式显示拒绝气泡。
- 支持像素风对话气泡，展示“文件来了”“好吃”“这个不好吃”等反馈。

交互细节：

- 挂件设置不放在阅读设置内，避免和字体、行高、透明度等阅读参数混在一起。
- 伪装预览应大致模拟当前老板模式浮窗样式，包括贴边顶部控制栏、正文区域和底部透明度/本章进度栏。
- 伪装预览不能撑破设置页可视区域；预览区域和正文示例内容都需要支持内部滚动。
- 伪装预览随当前选择的宠物、游荡开关和恢复方式联动。
- 选择“按老板键恢复”时，使用快捷键设置里的老板键，不新增第二套快捷键录制入口。
- WebView 挂件游荡只在当前应用窗口可视范围内移动；macOS 原生桌面顶层窗口的真实桌面游荡仍为待规划。
- 文件投喂当前只做悬浮、吃/拒绝动画和气泡反馈，不会自动导入或打开文件。

### 8.4 快捷键

已实现能力：

- 支持录制式快捷键设置。
- 支持快捷键冲突校验。
- 支持恢复默认快捷键。

当前默认快捷键：

- `Ctrl+Shift+H`：老板键 / 摸鱼模式切换。
- `Escape`：快速隐藏。
- `Ctrl+F`：搜索。
- `ArrowLeft`：上一章。
- `ArrowRight`：下一章。
- `Ctrl+H`：返回书架。

## 14. 待规划：桌宠挂件模式

本节记录用户对挂件功能的后续方向设想。当前这些能力尚未实现，不能在 README 或功能说明中写成已完成。

### 14.1 产品方向

当前老板模式收纳后的小狗挂件，后续希望升级为更完整的桌宠模式。
桌宠不只是静态图标，而是一个可配置、有动作、有反馈、可扩展对话的桌面宠物。

规划目标：

- 设置页新增“挂件设置”区域。
- 挂件形象支持选择，例如狗、猫。
- 老板模式收纳成挂件后，宠物显示在桌面顶层。
- 可配置是否允许宠物自动游荡。
- 开启游荡后，宠物会在桌面顶层自动移动，表现出走路动画。
- 宠物支持可扩展动作，例如狗坐着摇尾巴、猫舔毛、宠物无聊时待机动作。
- 后续可配置宠物无聊时随机弹出的台词。
- 后续支持挂件模式下的对话框互动。

### 14.2 文件拖拽互动

规划交互：

- 用户可把本地文件拖拽到桌宠上。
- 文件拖到宠物上方悬浮时，宠物进入“张嘴/准备吃”的动作。
- 如果文件格式属于 MoyuReader 支持的打开类型，后续可触发导入或打开逻辑。
- 如果文件格式不符合当前应用支持类型，宠物弹出气泡对话，例如“这个不好吃”。

交互约束：

- 拖拽悬浮反馈必须轻量，不能影响老板模式阅读窗口恢复。
- 不支持的文件格式只能给出反馈，不应静默失败。
- 文件拖拽导入或打开前仍需遵守现有书架和阅读进度规则。

### 14.3 资源需求

桌宠资源可以分阶段制作：

- 原型阶段：可继续用 CSS/SVG 像素块实现简单动作，验证交互。
- 正式阶段：建议使用像素风 sprite sheet，便于扩展动画帧和不同宠物。

建议最小资源集：

- 狗：走路、坐下摇尾巴、张嘴吃文件、疑问反馈。
- 猫：走路、舔毛、张嘴吃文件、疑问反馈。
- 每个动作按 10 帧作为当前目标规格，避免 2-4 帧导致动作过硬。
- 至少提供左右两个方向；如果后续要更强桌宠感，可扩展上下左右方向。
- 每个宠物建议统一画布尺寸，例如 `64x64` 或 `96x96`，方便窗口尺寸和命中区域稳定。

资源风格要求：

- 像素风。
- 小体积。
- 轮廓清晰。
- 和 MoyuReader 当前 Neubrutalism 风格兼容。
- 不要使用写实宠物图，不要偏 3D 卡通大头风。

### 14.4 当前原型资源

当前已生成一版可迭代的 SVG 像素风 sprite sheet 原型资源，并已接入 WebView 挂件、挂件设置和伪装预览。资源仍是原型级别，不代表最终美术质量。

资源路径：

- 狗：`frontend/src/assets/pets/dog/sprite.svg`、`frontend/src/assets/pets/dog/sprite.json`。
- 猫：`frontend/src/assets/pets/cat/sprite.svg`、`frontend/src/assets/pets/cat/sprite.json`。
- 生成脚本：`tools/generate-pet-sprites.mjs`。

资源规格：

- 单帧尺寸：`96x96`。
- 每个动作：`10` 帧。
- 每只宠物：`4` 个动作，共 `40` 帧。
- 资源格式：透明背景 SVG sprite sheet + JSON 元数据。

当前动作：

- 狗：`walk` 走路游荡、`sit_tail` 坐着摇尾巴、`mouth_open` 张嘴吃文件、`question` 疑问反馈。
- 猫：`walk` 走路游荡、`lick_paw` 舔毛、`mouth_open` 张嘴吃文件、`question` 疑问反馈。

后续接入桌宠播放时，应优先读取 JSON 元数据，不要在业务代码中硬编码帧坐标。
